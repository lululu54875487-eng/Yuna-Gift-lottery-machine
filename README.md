# 社群抽獎小工具

單檔 HTML 抽獎工具，可直接用瀏覽器開啟 `index.html` 使用，不需要安裝套件或啟動伺服器。

## 功能

- 支援一般抽籤抽人。
- 支援贈物號碼抽選。
- 支援 VIP 指定得主。
- 支援每人最多中獎數限制。
- 支援跳過動畫、取消抽獎、重新抽獎。
- 抽獎結果會附上時間、模式、有效參加者數、有效號碼數與設定摘要。

## 這版已優化

- 抽獎前會檢查格式錯誤、空姓名、空號碼、VIP 重複指定與不存在的 VIP 號碼。
- 同一人重複填同一號碼會自動只保留一次，避免重複增加中獎機率。
- 同名多列會合併，不再覆蓋前面填寫的號碼。
- 抽獎中可以取消；重新抽獎會先中止上一輪流程。
- 動畫區顯示使用者輸入時會先處理 HTML 特殊字元，避免輸入內容破壞頁面。
- 複製結果失敗時會提示瀏覽器權限限制。

## 使用方式

1. 下載或 clone 這個 repo。
2. 用瀏覽器開啟 `index.html`。
3. 貼上抽獎清單。
4. 視需求填寫 VIP 指定與中獎限制。
5. 點擊「開始抽獎」。

## 輸入格式

一般抽籤：

```text
璐璐、抽抽、芊芊
```

贈物抽獎：

```text
璐璐：21、35
抽抽：20、15
芊芊：21、20
```

VIP 指定：

```text
21：璐璐
35：抽抽
```
